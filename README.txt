以撒指北 · PWA 版（V6.2）
================================

这个文件夹是「可安装到桌面」的网页版，和单文件 HTML 内容完全一样，多了三样东西：
- manifest.webmanifest：应用名、图标、独立窗口
- sw.js：离线缓存（装好之后没网也能看）
- icon-192 / icon-512：桌面图标

────────────────────────────
【怎么用】
────────────────────────────

■ 方式一：今天就能用（不装东西）
1. 把 dist\以撒图鉴.html 传到手机
2. 用手机浏览器打开它
3. 浏览器菜单 →「添加到主屏幕」
   得到的是一个快捷方式，点开还是用浏览器打开本地文件
   （能用、能离线，但不是独立窗口）

■ 方式二：真正的 PWA（回家做，10 分钟）
PWA 必须在 http/https 下才能安装，本地文件不行。回家后任选一种：

A. 局域网（电脑和手机连同一个 Wi-Fi）
   电脑上进入本文件夹，执行：
     python -m http.server 8099
   手机浏览器打开：http://电脑IP:8099/
   注意：非 localhost 的 http 页面不能注册 Service Worker，
   Chrome 允许「添加到主屏幕」，但离线缓存可能不生效。

B. 静态托管（推荐，一劳永逸）
   把本文件夹整个上传到任意静态托管：
   GitHub Pages / Gitee Pages / Netlify / Vercel / 自己服务器
   拿到 https 地址后用手机浏览器打开 → 会弹出「安装应用」
   装好后是全屏独立窗口、有图标、离线可用

────────────────────────────
【文件说明】
────────────────────────────
index.html              主程序（单文件，含全部数据与图标）
manifest.webmanifest    应用清单
sw.js                   离线缓存
icon-192.png            图标（小）
icon-512.png            图标（大）

────────────────────────────
【注意】
────────────────────────────
- 手机上「添加到主屏幕」后，如果发现还是浏览器界面，说明当前环境不支持 PWA，
  属于正常现象，改用方式二部署到 https 即可
- 更新版本时：替换 index.html，并把 sw.js 里的 CACHE 版本号改一下（如 isaac-guide-v6.2），
  否则旧缓存不会刷新
