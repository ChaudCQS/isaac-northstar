# 以撒指北 · Isaac Northstar

《以撒的结合：忏悔》全 DLC 中文离线图鉴 —— 手机优先、单文件、可装到桌面的网页版。

**在线地址**：https://chaudcqs.github.io/isaac-northstar/
**当前版本**：V6.1

---

## 这是什么

一个自用的以撒查询工具。打游戏的时候想知道某件道具值不值得拿、这个房间是干嘛的、这层该往哪走，掏手机点两下就能查完，不用翻网页、不用联网。

整个应用打包成**一个 HTML 文件**（约 2 MB），道具图标、角色立绘、雪碧图全部内联在里面，双击就能开，断网也能用。

## 里面有什么

| 内容 | 数量 |
|---|---|
| 道具（含全 DLC） | 721 |
| 饰品 | 187 |
| 卡牌 | 93 |

| 套装 | 16 |
| 挑战 | 全部 |
| 进阶技巧 | 37 条 / 8 组 |
| 外号速查 | 192 条 |

**查得到**：中文名、英文名、编号、外号、拼音首字母、标签、词条，都能搜。搜「绿蘑菇」能搜到 1UP!，搜「撒旦圣经」能直接命中。

**看得清**：道具详情里有品质、评级、充能、来源池、标签、词条和效果说明；角色有血量和初始道具；挑战有关卡目标和解锁条件；说明栏有路线图、通关标记、机制、诅咒、兼容覆盖、进阶技巧和外号速查。

**用得顺**：
- 列表 / 网格两种视图，右上角切换，选择会记住
- 词条筛选，多选叠加
- 收藏夹（星标）
- 深色主题，为手机窄屏调过版式，滚动时顶栏自动收起
- 可「添加到主屏幕」当独立应用用，有离线缓存

## 怎么用

**方式一：直接用**

打开 https://chaudcqs.github.io/isaac-northstar/ 就能查。想装到桌面：

- iPhone：Safari 打开 → 分享 → 添加到主屏幕
- Android / 鸿蒙：浏览器菜单 → 安装应用 / 添加到主屏幕

装完是独立窗口，没有地址栏。

**方式二：本地文件**

下载仓库里的 `index.html`，双击打开即可，不需要服务器、不需要联网。

## 技术说明

- 纯静态：无框架、无构建工具、无依赖，一个 `<script>` 标签加载全部数据
- 构建：脚本把拆分后的 52 个资源和样式片段内联进单个 HTML，图标以 base64 雪碧图形式内嵌
- 离线：Service Worker 预缓存，断网可继续使用；更新时靠缓存版本号切换
- 兼容：手机上按 393 px 宽度设计（iPhone 15 Pro），更宽的屏（折叠屏、平板）自适应

## 数据来源与声明
